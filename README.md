# SuperColony Simulator

A real-time ant colony simulator prototype built with Rust and Macroquad. Place your queen, expand into neighbouring zones, gather finite food supplies to grow and sustain your colony, and watch automatic battles against rival ant armies.

## Run

Install [Rust](https://rustup.rs), then run from the project folder:

```bash
cargo run --release
```

On Linux or WSL, you can also use `./run.sh`. A graphical desktop is required; WSL users need WSLg.
